# 🐂🐴 牛马生涯 NiuMaCareer

> 一个工作 10 年的"牛马"写给在校生和职场新人的生存手册。

## 这是什么？

这是一份面向**在校大学生、即将毕业的学生以及初入职场的新人**的持续更新专栏。

记录了我在过去 10 年职业生涯中，在不同场景、不同阶段遇到的真实问题与思考——那些没人提前告诉你、但你迟早会碰到的事。

## 为什么叫"牛马生涯"？

因为打工人的日常就是这样。与其回避，不如正视。

希望这些内容能帮你少走一些弯路，或者在迷茫的时候知道——你不是一个人。

## 适合谁看？

- 🎓 在校大学生，对未来职业方向感到迷茫
- 📦 即将毕业，面临求职、选择 offer 的焦虑
- 🆕 刚入职场，不知道如何存活和成长
- 🔄 工作几年，遇到瓶颈想换方向或跳槽

## 内容方向

- **求职篇** — 简历、面试、选 offer、谈薪资
- **职场篇** — 沟通、协作、汇报、向上管理
- **成长篇** — 技术深度 vs 广度、转型、跳槽时机
- **心态篇** — 焦虑、内卷、躺平、自我认知
- **避坑篇** — 那些踩过的坑，希望你不用再踩
