# 📖 案例故事

> 真实的职业场景和经历复盘。每个案例都来自真实经历，有背景、有决策过程、有反思。

## 案例分类

| 类别 | 说明 |
|------|------|
| [面试案例](./interview/) | 成功的、失败的面试经历与复盘 |
| [职场案例](./workplace/) | 职场中遇到的真实场景与处理方式 |
| [选择案例](./decision/) | 人生关键路口的决策过程 |
| [AI 实践](./ai-practice/) | AI 时代的真实工作案例 |

## 案例模板

每个案例建议包含以下结构：

```markdown
# 案例标题

## 背景
> 当时的情况是什么？

## 问题
> 面临什么具体问题/选择？

## 我的做法
> 当时怎么做的？

## 结果
> 结果如何？

## 反思
> 如果再来一次，会怎么做？有什么教训？
```
