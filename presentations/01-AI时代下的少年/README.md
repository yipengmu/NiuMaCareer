## 大纲

### 第一部分：工科毕业生的3大工作阶段（1-5-10年）

> 从时间维度建立认知框架

- 第1年：存活期 — 从学生到职场人的身份切换
- 第5年：分水岭 — 选择深度还是广度
- 第10年：定义期 — 你开始定义工作，而非工作定义你

### 第二部分：生存-生活-生命

> 象限的建立与重心的变化

- 三层需求模型：先活下来 → 活得好 → 活出意义
- 不同阶段的重心迁移
- 关键认知：不要用第三阶段的标准评判第一阶段的选择

### 第三部分：AI的时代机会和找工作建议

> 实践案例 + 面试官视角

- AI时代的差异化人设策略
- 面试官视角：简历3秒法则
- 实操建议与可执行的行动项
